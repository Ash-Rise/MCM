# C题验证合同

> 状态：第三阶段冻结版本。本文冻结输入、输出、验证指标、成功判据和阻断条件，不冻结任务二的最终模型。
> 权威顺序：原题 DOCX → `decisions.md` → `model-design-report.md` → 本验证合同 → 后续实现与结果。

## 1. 语义审计

### 1.1 已冻结的人类所有语义

- **DP-C-001=A：** 主诊断直接使用数据包给定偏差率；参考示例只在分类完成后核验。
- **DP-C-002=A：** 主维修排序使用15天历史平均每日绝对可恢复损失；第16天增发量只作补充。

### 1.2 当前无需新增人工确认

没有发现仍需立即确认的人类所有语义选择：

- 任务二目标由原题确定为“第16天当前未修复运行状态下的全站总发电量及不确定性”，M0/M1/M2只是技术候选。
- “修复后”按恢复到官方偏差率定义中的正常反事实解释。这是当前题意下闭合模型所必需且最直接的解释；若后续需要部分修复率或残余故障率，则会改变提升量含义，必须提交新 Decision Proposal。
- 收益可加只在题目未提供不等维修成本、串联失配、逆变器限发、共享停机或组合约束的范围内成立。它是明确的建模适用条件，不是对真实电气系统无耦合的普遍断言。

### 1.3 AI所有技术选择

本合同冻结下列技术规则：数据校验、阈值边界实现、遮挡筛查统计量、逐日留一验证、模型资格门槛、一标准误差选择规则、区间诊断、反事实数值反演和稳定排序。若技术证据要求改变题目目标、分类语义、维修收益口径或组合约束，则技术选择停止并回到 Decision Proposal。

## 2. 共用数据合同

### 2.1 输入

- 100条组件参数：组件编号、组串、方位角、倾角、额定功率、投运年限。
- 100×15个组件日发电量，单位 kWh。
- 100个给定偏差率，输入时由百分数转换为小数。
- 第1—15天辐照度、温度、风速和天气类型，以及第16天预报。
- “参考示例”列，必须与任务一主输入隔离。

### 2.2 共用成功判据

- 组件编号恰为 `PV001`—`PV100`，唯一且参数表与发电量表一一对应。
- 每个组件恰有15个有限数值；天气表恰有15个历史日和1个预报日。
- 单位与原题一致；任何解析差异回到 DOCX 核对。
- 每日全站总发电量必须等于100块组件当日值的独立求和。
- 参考示例列从分类函数输入中删除后，任务一仍能完整运行。

### 2.3 共用失败模式

- DOCX抽取错列、百分数/小数混用、天序错位、组件重复或遗漏；
- 将1500个组件—日观测误当成1500个独立气象样本；
- 用参考示例反向生成诊断结果；
- 后续代码或结果静默改写 Accepted Decisions。

任一共用判据失败时，三个任务均不得继续产生正式结果。

## 3. 任务一验证合同

### 3.1 输入

- 主输入：组件编号与给定偏差率 `b_i`。
- 干扰筛查输入：`E_id`、`H_d`、组串、方位角、倾角、投运年限。
- 核验专用输入：参考示例标签。

### 3.2 输出

- 每块组件的官方三分类结果：正常、隐裂或热斑；
- `shading_suspect`、遮挡筛查分数及稳定性说明，且不得覆盖官方分类；
- 三类数量和按组串、方位角、倾角、投运年限分组的计数、分母与比例；
- 参考示例一致性审计和超出官方阈值定义域的记录清单。

### 3.3 验证指标

- 数据覆盖率：有有效偏差率的组件数/100；
- 分类完备率：成功进入官方三类的组件数/100；
- 参考一致率：独立分类后与参考示例一致的组件数/100；
- 边界正确性：`-15%`、`-5%`、`+5%`三个精确测试点；
- 遮挡筛查稳定性：同配置正常同伴与全体正常同伴两种参考下的标志一致性。

### 3.4 冻结的遮挡筛查规则

1. 对所有 `H_d>0` 的日计算 `q_id=E_id/H_d`；若存在 `H_d<=0`，该日不进行此归一化并报告。
2. 以主分类为正常的组件构成参考集。优先使用同一 `(方位角, 倾角)` 且不少于5块的正常同伴；不足5块时回退到全部正常组件。
3. 计算组件相对同伴日中位数的比值，并对其对数序列计算稳健离散度 `D_i=1.4826×MAD`。
4. 若 `D_i` 高于正常参考集中 `D` 的中位数加 `3×1.4826×MAD(D)`，且至少2天出现方向一致或具有时间局部性的异常，则标记为 `shading_suspect`。
5. 若同配置参考与全体正常参考给出不同标志，标记为“遮挡筛查不稳定”，不作确定遮挡判断。

该规则只识别异常时间波动；稳定低发电仍按官方偏差率分类。

### 3.5 成功判据

- 100个组件全部满足数据覆盖；当前数据全部落入官方三分类定义域，三类计数之和为100。
- 分类过程不读取参考示例；完成后参考一致率应为100%。若不一致，必须列出差异并回查解析、单位和边界，不得复制参考标签修正。
- 遮挡筛查为每个组件返回可审计状态，且不改变官方类别。
- 所有分布表同时给出计数和组内比例，并明确“不作因果解释”。

### 3.6 可能失败模式

- 出现 `b_i>5%`，题面未定义其三分类；
- 辐照度为零、发电量非正或同伴组过小导致对数/稳健筛查不可用；
- 传感器误差与移动遮挡具有相似时间模式；
- 组串、角度、倾角和年限混杂却被解释成因果效应；
- 热斑或隐裂未经红外/电致发光检查而被解释为物理确诊。

## 4. 任务二验证合同

### 4.1 输入

- 第1—15天全站总发电量 `Y_d=Σ_i E_id`；
- 同期 `H_d`、`T_d`、`W_d`；天气类型只作残差解释，不作为主候选特征；
- 第16天的 `H_16`、`T_16`、`W_16`。

组件倾角和方位角随日不变，在固定站点总量模型中由总体性能系数吸收，不作为伪独立日特征。

### 4.2 输出

- M0、M1、M2每个候选的15个逐日留一预测和误差；
- MAE、RMSE、最大绝对误差、归一化MAE、交叉验证 `R²` 与全样本 `R²`；
- 全样本和15个留一拟合的参数、参数稳定性、设计矩阵稳定性和影响诊断；
- 按冻结规则选择的模型及可复核理由；
- 第16天点预测、95%期望值置信区间和95%单日预测区间；
- 适用范围与未识别因素。

### 4.3 模型比较协议

1. 独立样本单位固定为“日”，对M0、M1、M2执行完全相同的15折逐日留一验证。
2. 先进行模型资格检查，再比较误差。未通过资格门槛的模型不得因训练拟合更好而入选。
3. 主指标为逐日留一 MAE；RMSE、最大绝对误差和交叉验证 `R²` 为辅助指标。
4. 对MAE最小模型的15个绝对误差计算标准误。所有 `MAE <= 最小MAE + 该标准误` 的合格模型进入一标准误集合。
5. 从一标准误集合中选择自由参数最少的合格模型；复杂度顺序为 M0、M1、M2。该顺序只是简约规则，不是提前指定M0获胜。
6. 若扩展模型不在一标准误集合中但MAE更低，它仍须满足：至少8/15天的绝对误差优于更简单模型，且单个日期贡献不超过全部正向误差改进的50%。

### 4.4 参数与共线性资格门槛

所有候选必须满足：

- 每个留一训练矩阵满列秩，所有参数和预测有限；
- 历史范围及第16天预测均非负；
- 辐照度主效应为正；
- 删除任意一天后，第16天预测相对全样本预测的偏离不超过 `2×LOOCV RMSE`。

M1附加门槛：

- 截距的95%置信区间应包含0；否则M1只作为M0失配诊断，不作为物理预测模型入选。

M2附加门槛：

- 标准化非截距设计矩阵条件数不超过30；超过30即判定多重共线性使扩展不可辨识；
- 温度效应不得为正，风速效应不得为负；
- 某天气系数若在超过5/15个留一拟合中落在约束边界0，则该效应视为未获支持，M2必须缩减后重新作为同族候选验证；
- 任一声明为有效的非零系数在留一拟合中不得改变物理符号，且删除单日后不得相对全样本估计变化超过100%；接近0导致相对变化无定义时按“未获支持”处理。

这些门槛优先于拟合优度，防止因温度、风速与辐照度共线而选择表面更复杂的模型。

### 4.5 区间验证指标

- 区间有限且有序：`预测区间下界 <= 置信区间下界 <= 点预测 <= 置信区间上界 <= 预测区间上界`；
- 逐日留一覆盖率和平均区间宽度，仅作低分辨率诊断；
- 残差尺度在 `Y` 与 `Y/H` 两种表示下的稳定性；
- Student-t区间与按日残差自助法敏感性结果的差异。

### 4.6 成功判据

- M0/M1/M2均按同一逐日留一协议评估，没有随机拆分或组件级泄漏。
- 至少M0通过资格门槛；最终选择可由保存的指标和规则机械复现。
- 入选模型同时通过预测误差和参数/设计稳定性检查；不因较高全样本 `R²` 选择不稳定扩展。
- 若M2因共线性或参数不稳定失败，明确淘汰或缩减，不追加复杂机器学习模型。
- 第16天同时给出点预测、95%置信区间和95%预测区间，并明确15天数据不能证明精确95%覆盖率。

### 4.7 可能失败模式

- 温度、风速与辐照度高度共线，M2系数不可辨识；
- 单个低辐照或异常日支配扩展模型的误差改进；
- M1通过截距吸收物理上不合理的零辐照发电量；
- 残差异方差使原尺度Student-t区间失真；
- 第16天气象超出历史范围、故障状态改变、发生限发或逆变器异常；
- 所有简单候选均出现可重复结构性残差。此时先定位缺失机制；只有简单模型确实不足才提出最小扩展，涉及语义变化则先提交 Decision Proposal。

## 5. 任务三验证合同

### 5.1 输入

- 任务一确定的热斑和隐裂组件集合；
- 每块故障组件15天发电量均值 `mean(E_i)`；
- 给定偏差率 `b_i`；
- 任务二最终入选模型，仅用于第16天补充增发量。

### 5.2 反事实估计流程

1. 将偏差率从百分数转换为小数，并计算 `mean(E_i)`。
2. 依据官方定义反演正常反事实：`E0_i = mean(E_i)/(1+b_i)`。
3. 计算历史平均每日绝对可恢复损失：`L_i=E0_i-mean(E_i)`，单位 kWh/天。
4. 仅对任务一判为隐裂或热斑的组件排序；正常组件不得进入维修候选。
5. 按 `L_i` 降序取前10；第16天增发量在名单冻结后另行估计，不反向改变主排序。
6. 以偏差率显示精度±0.05个百分点构造端点敏感性，检查损失和第10名边界稳定性。

物理理论或健康同伴反事实只能作为DP-C-001允许的敏感性分析，不能替换步骤2的主反事实。

### 5.3 输出

- 全部故障组件的 `mean(E_i)`、`b_i`、`E0_i`、`L_i`、排序和舍入敏感性；
- 主排序前10名单；
- 15天口径下的合计平均每日增发量和全站相对提升率；
- 第16天气象下的补充增发量及其不确定性；
- 可加性适用条件、临界并列和敏感性说明。

### 5.4 验证指标

- 偏差率重构误差，单位为百分点；
- 反事实有限性与损失非负率；
- 排序不变量：`min(入选L) >= max(未入选L)`；
- 第10/11名损失差及其舍入敏感性区间是否重叠；
- 前10合计损失与全站修复提升的加和误差；
- 允许的敏感性模型下前10成员重合率，仅作稳健性说明。

### 5.5 “排序取前10”适用条件

以下条件必须全部成立：

1. 每修复一块组件消耗相同的一单位预算；
2. 最多修复10块，没有不同成本、工期或必选/互斥约束；
3. 每块组件的 `L_i` 非负且不依赖其他组件是否修复；
4. 选定集合的总收益等于成员收益之和；
5. 目标是最大化DP-C-002定义的15天平均每日绝对可恢复发电量。

满足时，交换论证保证降序前10为精确最优解，无需整数规划、背包模型或启发式算法。若任一条件失败，当前排序合同失效；不得直接添加优化模型，必须先判断是否涉及新的题意或资源语义并按需提交 Decision Proposal。

### 5.6 成功判据

- 每块故障组件满足 `-1<b_i<-0.05`、`1+b_i>0`，反事实有限且 `L_i>0`。
- 重构偏差率与给定值的差不超过0.05个百分点加数值容差。
- 可加性五项条件均有题面依据或显式建模假设，且没有输入数据与其冲突。
- 前10名单满足排序不变量；若第10/11名在舍入敏感性下交换，仍按中心给定值生成主名单并明确“边界不稳定”。
- 主提升量严格等于10块历史平均损失之和；第16天补充值与主排序口径分离。

### 5.7 可能失败模式

- 偏差率舍入改变第10名附近顺序；
- 修复只能恢复部分损失；
- 串联电流瓶颈、逆变器限发或共享停机使收益不可加；
- 维修成本或工期并不相同；
- 用百分比损失而非kWh/天排序；
- 第16天条件反向替换DP-C-002的历史排序。

## 6. 合同冻结与变更规则

- 后续实现必须逐项产生本合同要求的输入审计、指标和失败信息。
- 普通数值库、函数组织、文件格式细节属于AI所有技术选择。
- 修改阈值语义、偏差率来源、任务二目标、维修时间尺度、修复效果定义、收益可加性或预算含义，必须先进行 Decision Review/Proposal。
- 修改数值容差或稳定性阈值时，必须说明具体失败证据及对模型选择的影响，不得为保留复杂模型而事后放宽门槛。
