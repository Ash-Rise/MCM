# Problem B Project Instructions

Follow the repository-root `AGENTS.md` and `MCM_AI_Governance.md`.

For this project, treat a completed modeling or implementation phase that adds or regenerates core source code, formal numerical results, or multiple downstream artifacts as a substantial integration-risk change. Before stopping at such a phase boundary, place the coherent change on a dedicated branch, commit it, push the branch, and open one pull request against `main`; then stop before merge for human review. Small localized edits continue to use the repository's normal PR boundary.
