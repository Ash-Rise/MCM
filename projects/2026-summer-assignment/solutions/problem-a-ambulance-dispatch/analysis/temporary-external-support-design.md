# 任务三临时外援机制设计

## 1. 研究目的

在现有12辆车和事故感知策略$B_E$的基础上，引入0至6辆临时外援车辆，计算事故期平均响应时间、尾部响应、排队和延迟惩罚随外援数量的变化。该实验回答“增加多少车辆能够把响应时间降低到什么程度”，并用单位车辆带来的时间改善和延迟成本节省衡量资源使用效率。

题目没有给出外援车辆的调集费用，因此不构造带有虚拟价格的净成本目标，也不声称存在唯一经济最优车辆数。结果报告各车辆数下的完整响应曲线、边际收益和盈亏平衡调集成本。

## 2. 冻结假设

1. 每次情景只有一个需求区域发生事故，事故区域依次遍历R1至R10，其他区域维持日常强度。
2. 事故持续时间沿用现有10个仿真节点：0.5、1、2、4、5、6、8、10、11和12 h。
3. 外援到场时间为0，即事故在$t_0$被确认时立即激活；事故发生前不参与预热、派车或未来覆盖损失计算。
4. 外援驻扎在事故区域最近站点附近的临时集结位置，永久停车容量仅约束原有12辆车。驻点映射为：R1-S1、R2-S2、R3-S3、R4-S4、R5-S5、R6-S6、R7-S3、R9-S1、R10-S4。R8到S4和S6距离相同，外援按数量尽量均分；奇数辆时先放S4。
5. 外援与普通车辆采用相同的3 min准备时间、45 km/h速度、45 min任务占用和每日12次接单上限，任务完成后返回临时驻点。
6. 外援加入事故感知策略$B_E$的候选车辆池，不设置备用保护。事故期停止生成新呼叫后，外援继续服务已经到达的排队呼叫，直至系统排空。
7. 对相同事故区域、持续时间和随机种子，0至6辆外援使用完全相同的背景与事故呼叫流。
8. 事故持续时间没有概率分布，所有结果按$H$分别报告，不跨时长合成为单一总体分数。对10个事故区域可给出等权情景均值和最不利区域结果，等权值仅表示场景汇总，不解释为真实事故期望。

## 3. 车辆驻点

对事故区域$k$，单辆外援驻点为距离$d_{kj}$最小的站点$j$。除R8外，每个区域都有唯一最近站点。R8到S4、S6的距离均为1.414 km，因此多辆外援在两站间交替配置：

| 外援数量 | R8驻点配置 |
|---:|---|
| 0 | 无 |
| 1 | S4 |
| 2 | S4、S6各1辆 |
| 3 | S4两辆、S6一辆 |
| 4 | S4、S6各2辆 |
| 5 | S4三辆、S6两辆 |
| 6 | S4、S6各3辆 |

该规则保持可解释性，不利用事故持续时间或随机种子重新优化驻点。

## 4. 评价指标

对给定事故区域、持续时间和随机种子，记配置$m$辆外援时的事故期平均响应时间为$T_m$，事故期延迟惩罚总额为

$$
P_m=\sum_{e\in\mathcal E_H}200\max(T_{e,m}^{\mathrm{resp}}-4,0).
$$

其中$\mathcal E_H$为事故期到达的全部呼叫。主要性价比指标为：

1. 累计平均响应改善：$G_m=T_0-T_m$；
2. 第$m$辆车的边际响应改善：$g_m=T_{m-1}-T_m$；
3. 累计避免延迟惩罚：$S_m=P_0-P_m$；
4. 平均每辆外援避免的延迟惩罚：$A_m=S_m/m$；
5. 第$m$辆外援的盈亏平衡调集成本：$B_m=P_{m-1}-P_m$。

若第$m$辆车的实际调集成本低于$B_m$，则其节省的延迟惩罚高于调集成本。由于题目未给出实际调集成本，论文报告$B_m$而不直接计算净收益。

同时保留事故期P95响应时间、4分钟内到达率、事故区平均响应时间、最大排队呼叫数和事故结束时积压量，用于防止平均值掩盖严重拥堵。

## 5. 实验规模与输出

完整实验包括10个事故区域、10个持续时间节点、10个随机种子和$m=0,1,\ldots,6$共7种外援数量，合计7000次仿真。$m=0$必须与当前$B_E$冻结结果一致。

结果文件至少包括：

- 复制级外援结果；
- 按事故区域、持续时间和外援数量汇总的均值与95%置信区间；
- 按持续时间汇总10个事故区域情景的响应与性价比表；
- 各持续时间下的最不利事故区域结果。

正式图优先采用一个双面板结果图：左侧展示不同持续时间下平均响应时间随外援数量的变化，右侧展示每增加一辆外援的边际响应改善和盈亏平衡调集成本。两类量纲不共用双纵轴，分别置于独立面板。

## 6. 测试与验收

实现前新增以下失败测试：

1. 最近站点映射与R8均分规则正确；
2. 外援在事故开始前不可派出，事故开始时立即可用；
3. 外援数量为0时完整复现现有$B_E$结果；
4. 外援与普通车辆采用相同任务时长、速度、准备时间和每日接单上限；
5. 同一情景下不同$m$使用相同呼叫摘要；
6. 性价比指标由复制级成对结果计算，$m=0$不计算除零型指标；
7. 复制级行数为7000，区域、时长、种子和车辆数单元完整；
8. 论文表格与图的数据能够由结果文件确定性重建。

最小实现测试通过后再运行小规模切片；确认$m=0$复现和外援激活边界正确，才启动完整7000次仿真。
