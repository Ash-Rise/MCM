# 论文协作流程通知

论文协作统一使用 GitHub。请安装 VS Code、Git，强烈建议安装 GitHub CLI；接受邀请后 Clone `MCM`。`main` 是主线，项目内的 `paper/paper.md` 是唯一正文基准。修改时由 AI 从最新 `main` 创建 `review/*` 分支，只改这份 Markdown，完成检查、Commit、Push 和 PR。请在 `Pull requests` 查看 PR、`Files changed` 和审核意见。我负责最终 Merge，AI 不得自动合并。数字、公式、模型、引用或结论冲突时暂停，由我决定。仅提建议可用 Issues，无需分支。
