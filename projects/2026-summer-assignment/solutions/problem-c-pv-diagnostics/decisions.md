# Problem C Accepted Decisions

## DP-C-001 / 偏差率使用方式

**Status:** Accepted

**Decision:** 采用选项 A。将数据包给出的“偏差率(%)”作为正式诊断输入，独立应用题面阈值；“参考示例”列仅用于结果核验，不作为模型输入或训练标签。

**Reason:** 原题没有给出唯一重建理论发电量所需的完整物理参数，直接使用正式数据字段最忠实于题面且避免由补充参数改变诊断边界。

**Supersedes:** None

**Implications:** 任务一的主诊断口径为官方偏差指标与阈值规则。物理理论基准和同配置健康组件经验基准仅可作为敏感性分析或讨论，不替代主口径；结论需说明其诊断含义和物理鉴定边界。

## DP-C-002 / 维修收益排序时间尺度

**Status:** Accepted

**Decision:** 采用选项 A。以15天历史期的平均每日绝对可恢复发电量损失（kWh/天）作为维修收益主排序指标。

**Reason:** 该口径利用全部历史天气，避免由单日预报主导长期运维优先级，并直接对应题目要求的绝对发电量损失。

**Supersedes:** None

**Implications:** 主修复名单按历史平均每日绝对损失排序。第16天预报条件下的可恢复损失及长期累计收益方案仅作敏感性分析或讨论，不替代主排序；修复后提升需明确时间口径。
